홍도시 도시 시스템 포트폴리오 프로젝트

파일 구성
- index.html : 페이지 구조와 화면에 표시되는 콘텐츠
- styles.css : 디자인, 색상, 반응형 레이아웃
- script.js : 도시 시뮬레이터의 동작과 게임 로직

실행 방법
1. 네 파일을 같은 폴더에 둡니다.
2. index.html을 웹 브라우저로 엽니다.
3. 인터넷 연결이 있으면 Google Fonts 글꼴도 불러옵니다.

분리 기준
원본 HTML의 본문과 콘텐츠는 유지하고, 내부 CSS와 JavaScript를 별도 파일로 옮겼습니다.
게임 규칙이나 문구를 임의로 수정하지 않았습니다.
